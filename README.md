Free audiobook generator 

Simply type in the name of the book you want to listen to, or enter in a theme (i.e. defense spending in Ukraine). 

It will either download the exact name of the book form Anna's archive and convert it to an audiobook, or do a deep search on the topic 
using Exa API and convert it to an audiobook version of the articles.
